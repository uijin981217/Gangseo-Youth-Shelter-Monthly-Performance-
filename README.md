# 쉼터 월간 실적 자동화

개인별 서비스 기록 엑셀로 **안전망 실적 엑셀**과 **쉼터 운영일지(.hwpx)**를 한 번에 만드는 페이지예요.

- 사용 주소: https://uijin981217.github.io/Gangseo-Youth-Shelter-Monthly-Performance-/
- 모든 처리는 **각자의 브라우저 안에서만** 이루어져요. 넣은 파일은 어디로도 전송되지 않습니다.
- 인터넷 없이 쓰려면 이 저장소를 내려받아(Code → Download ZIP) 압축을 풀고 `index.html`을 여세요.

## 쓰는 법
1. 대상 월을 고르고, 아래 파일들을 한꺼번에 끌어다 놓아요.
   - 개인 파일: `홍길동 n월.xlsx`
   - 지난달(또는 이번 달) 안전망 실적: `2026년 n월 안전망 실적.xlsx`
   - 근무표(선택): `2026년 n월 근무표.xlsx` → 일지 근무자 칸 자동 입력
   - 운영일지 양식(선택): 없으면 내장 양식 사용
2. 「확인하기」에서 입소생 파일 도착, 입·퇴소, 직접 입력 실적을 확인해요.
3. 「두 파일 한 번에 만들기」를 누르고 내려받아요.

## 주의
- 이 저장소는 공개예요. **업무 파일(엑셀·한글)은 절대 올리지 마세요.** (`.gitignore`로 막아 두었어요)
