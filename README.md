# 쉼터 월간 실적 자동화

개인별 서비스 기록으로 **안전망 실적 엑셀**과 **쉼터 운영일지(.hwpx)**를 한 번에 만드는 페이지예요.

- 사용 주소: https://uijin981217.github.io/Gangseo-Youth-Shelter-Monthly-Performance-/
- 모든 처리는 **각자의 브라우저 안에서만** 이루어져요. 넣은 파일은 어디로도 전송되지 않습니다.
- 인터넷 없이 쓰려면 이 저장소를 내려받아(Code → Download ZIP) 압축을 풀고 `index.html`을 여세요.

## 넣는 파일 (한꺼번에 끌어다 놓으면 이름을 보고 알아서 나눠요)
| 파일 | 예 | 필수 |
|---|---|---|
| 개인 서비스 기록 | 내보낸 그대로 `실행목록[…].xlsx` 또는 이름·월을 붙인 파일 (`홍길동 n월.xlsx`, `n월 홍길동.xlsx`, `n월 홍길동 2.xlsx` 등 순서·번호 상관없음) | 필수 |
| 근무표 | `2026년 n월 근무표.xlsx` | 선택 (일지 근무자 칸) |
| 아웃리치 | 내보낸 그대로 `아웃리치[…].xlsx` | 선택 (아웃리치 실적·일지) |
| 사후관리대장 | `사후관리대장 - 2026년.hwp` (그대로) | 선택 (사후관리 실적·일지) |
| 안전망 실적 | 지난달 `2026년 n월 안전망 실적.xlsx` | 선택 (이 PC가 지난번 결과를 기억) |
| 운영일지 양식 | `.hwpx` | 선택 (없으면 내장 양식) |
| 연간 기록 파일 | `2026년 이용자현황.xlsx`, `2026년 학업, 자립, 법률,의료지원.xlsx` | 선택 (그 달 시트·묶음을 채워 줌) |

## 쓰는 법
1. 파일을 넣고, 이름 없는 원본 파일은 아이 이름을 확인해요(추천 이름이 미리 골라져 있어요).
2. 「확인하기」에서 입소생 파일 도착, 입·퇴소, 아웃리치, 직접 입력 실적, 운영일지 작성 규칙을 확인해요.
3. 「두 파일 한 번에 만들기」를 누르고 내려받아요.

## 주의
- 이 저장소는 공개예요. **업무 파일(엑셀·한글)은 절대 올리지 마세요.** (`.gitignore`로 막아 두었어요)
- 이 PC가 기억하는 내용(지난 실적, 작성 규칙)은 그 PC 브라우저에만 저장돼요.
